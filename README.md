# Semear — Landing Page

Landing page desenvolvida para a **Semear**, espaço multidisciplinar de saúde em Diadema-SP (ABC Paulista), especializado em desenvolvimento e reabilitação de crianças, adolescentes e adultos.

🔗 **Site no ar:** https://semear-seven.vercel.app

## Sobre o projeto
Site institucional criado para apresentar a clínica, seus serviços e equipe, e facilitar o contato de novos pacientes via WhatsApp.

## Seções
- Apresentação e chamada para contato via WhatsApp
- Sobre a clínica
- Serviços (fisioterapia, terapia ocupacional, psicologia, fonoaudiologia e mais)
- Equipe
- Convênios atendidos
- Depoimentos de pacientes
- Contato e horários de funcionamento

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Deploy: Vercel
